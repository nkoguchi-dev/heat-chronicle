# ヒートマップ画面

## 目的

利用者が日本の観測地点と気温種別を選び、日別気温の長期的な変化をヒートマップで探索できるようにします。

## 画面構成

- アプリケーション名と、選択中の気温種別を含む説明
- 都道府県、観測地点、最高・最低・平均気温の選択欄
- データ取得の状態、進捗、エラー、再試行操作
- 年と日付を軸にした気温ヒートマップ
- 気温と色の対応を示す凡例
- 古い期間を追加するボタン
- テーマ切替、気象庁の出典、ソースコードへのリンク

## 地点と気温種別の選択

初回表示では安全な既定の都道府県、観測地点、最高気温を選択し、対応するデータを読み込みます。URLに有効な選択がある場合は、その地点と気温種別を復元します。不正または不足した選択は、利用可能な安全な状態へフォールバックします。

都道府県を変更すると、それまでの地点とヒートマップをクリアして、選択した都道府県の観測地点を読み込みます。観測地点を選ぶと、その地点の最新期間を読み込みます。気温種別を変更すると、取得済みデータから対応する最高・最低・平均気温へ表示を切り替えます。

## ヒートマップと期間

縦方向を年、横方向を日付として、日別気温を色で表示します。値がない日は欠測として区別します。セルをポインターで指した場合は、日付と選択中の気温を表示します。

最初に最新年を含む最大50年分を表示します。さらに古い観測記録がある場合は、次の最大50年分を追加できます。追加中も既存のヒートマップを維持し、観測開始年へ到達したら追加ボタンを表示しません。

未取得の月がある場合は、新しい月から順に間隔を空けて取得し、届いたデータを段階的にヒートマップへ反映します。

## URLと状態の復元

選択した都道府県、観測地点、気温種別をURLへ保持します。URLの具体的なキー名と変換規則は、利用者向けの振る舞いを維持する範囲でエンジニアリング上の判断とします。

- 選択を含むURLへ直接アクセスまたは再読み込みした場合、同じ選択とヒートマップを復元する
- 地点または気温種別の変更ごとに、ブラウザ履歴から以前の状態へ戻れるようにする
- 戻る・進む操作では、URL、選択欄、説明、ヒートマップを同じ状態へ復元する
- 不正または利用できない値では、画面を操作できない状態にせず、安全な初期状態へフォールバックする
- 追加表示した期間はURLへ保持せず、共有または再読み込み時は最初の期間から開始する

## ローディングとエラー

都道府県一覧、観測地点一覧、最初の気温データ、古い期間の追加を区別して状態を表示します。月別取得が必要な場合は、対象年月と進捗を表示します。

一覧または最初の気温データを取得できない場合は、理由を理解できるメッセージと再試行操作を表示します。月別取得の一部が失敗した場合は、取得済みデータを表示したまま一部失敗を案内し、同じ範囲を再試行できるようにします。

古い期間の追加に失敗した場合は、既存の期間を維持し、失敗した期間と再試行操作を表示します。地点を変更した場合、以前の地点に対する遅い応答で新しい表示を上書きしません。

## レスポンシブ対応

- 狭い画面では選択欄を縦方向に並べ、操作可能な幅を確保する
- ヒートマップが画面幅を超える場合は横スクロールで確認できることを案内する
- 広い画面では選択欄を横方向に並べ、ヒートマップを中央に表示する

## アクセシビリティ

- 選択欄、ボタン、リンクは識別できる名前を持ち、キーボードで操作できる
- ローディング、進捗、エラーは支援技術へ通知し、エラーには再試行手段を関連付ける
- フォーカス位置を視覚的に確認でき、色だけで状態やエラーを区別しない
- ヒートマップのスクロール領域はキーボードでフォーカスでき、目的を識別できる名前を持つ
- Canvasのセル単位の文字ラベル、個別フォーカス、代替一覧は要件としない
