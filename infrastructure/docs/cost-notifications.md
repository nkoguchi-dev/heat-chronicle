# 費用通知の対象範囲と対応

費用Budgetは共有基盤が所有し、アプリ側で重複作成・importしません。
予算額・通知先・実識別子・到達試験記録は公開コードへ保存しません。
対象account・service・filter・CostTypesを実設定で照合し、アプリ費用が含まれるか確認します。
Organization合算の通知をアプリ単独の異常とみなさず、クレジット等の相殺にも注意します。

[AWS Budgets](https://docs.aws.amazon.com/cost-management/latest/userguide/budgets-managing-costs.html)の更新には遅延があります。
即時制限や厳密な費用上限ではなく、API停止でも静的配信・ログ等の費用は残りえます。

1. 通常のAWS入口からBudget・期間・更新時刻とサービス/account別明細を確認します。
2. アプリが原因なら[API調査](./api-observability.md)と静的配信・DynamoDB等を照合します。
3. 継続する異常には利用者影響・対象資源・復旧値を示し、停止判断の承認を得ます。
4. 対処は非公開記録へ残します。通知を消すために予算を上げません。

通知状態OK、請求書受信、Discord成功はBudget警告メールの本人受信の証明ではありません。
実通知の受信確認を優先し、受信実績がなければ試験対象・一時設定・復元・受信判定を具体化して承認を得ます。
しきい値の独断変更・課金誘発・既存宛先の削除再登録は行いません。
